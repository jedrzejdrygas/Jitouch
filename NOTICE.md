# Modification notice

This repository is a modified source version of Jitouch 2.82.1.

Changes made in September 2026:

- Enabled configured horizontal three-finger trackpad swipes in Firefox while
  retaining upstream Safari behavior.
- Added source build, local installation, preference backup and restoration,
  Accessibility reset, validation, and diagnostic tooling.
- Made the preference pane prefer the normal `/Applications/Jitouch.app` runtime
  while retaining its embedded-app fallback for manual installations.
- Added documentation and continuous integration for the source-only fork.
